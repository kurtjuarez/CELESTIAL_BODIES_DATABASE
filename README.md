
# Overview

This is a certification project used to improve my skills on becoming a data analyst.

# Objectives

- Design and build a relational database representing galaxies, stars, planets, and moons.
- Create and manage multiple related tables using PostgreSQL.
- Establish relationships between tables using primary keys and foreign keys.
- Define appropriate data types and constraints to maintain data integrity.
- Populate database tables with records using SQL INSERT statements.
- Organize astronomical data into a structured relational database.

# Tools I Used

- **SQL:** Used to build the database, insert values, and add appropriate data types and constraints
- **PostgreSQL:** Used to execute SQL queries and perform data analysis.
- **Visual Studio Code:** Used to write and organize SQL queries.
- **Git:** Used for version control to track changes and manage the project during development.
- **GitHub:** Used to store and document the project.

# Skills Demonstrated

- Relational Database Design
- Database Schema Creation
- Table Creation and Management
- Primary Keys and Foreign Keys
- One-to-Many Relationships
- Data Types and Constraints
- Data Insertion and Manipulation
- Data Integrity
- Database Structure and Organization

# Project Files

- universe.sql — Contains SQL queries to build database, insert values, and add data types and constraints.

# What I Learned

I further improved my skills on creating databases, adding values, choosing the appropriate data types for certain values, and adding constraints to either further secure rows getting added to the database or link tables.
